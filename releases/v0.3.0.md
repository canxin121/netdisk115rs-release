# v0.3.0：专注本地媒体库，统一播放清晰度

本版将媒体管理收敛到项目自己的本地索引和多媒体库，同时补齐视频清晰度选择及外部播放器的一致性。

## 新增与改进

- 视频播放前、播放中可选择原画或实际可用的转码清晰度；不可用档位明确禁用。
- 完整播放器、QuickLook、右键外部播放、复制播放链接共享按账号与文件保存的清晰度选择。
- 外部播放票据固定账号、文件和档位，按接收播放器的 User-Agent 重新取源；所选档位失效时明确报错，不悄悄回退原画。
- 切换清晰度保留播放位置与播放/暂停意图，并防止迟到的旧请求覆盖新视频源。
- 手机端保留清晰度入口，并验证 320px 窄屏布局。

## 兼容性变化

**原生媒体功能已移除，不只是隐藏入口。**

- 删除 115 原生观看／我听、旧音乐听单、原生相册的 Web 页面、管理 API、CLI、文件加入工作流及专用缓存。
- 删除 `media` 原生媒体命令树，以及 `download-api definition`、`download-api related`；本地媒体管理继续使用 `library`。文件播放诊断保留 `download-api video-play`，字幕查询使用 `download-api subtitle`。
- 删除原生 `/api/multimedia/*`、`/api/music/*`、`/api/photo/*`、`/api/fs/music/*`、`/api/fs/photo/*` 等库管理入口，以及云端播放历史读写。依赖旧接口或命令的脚本需要调整。
- 播放进度只保存在本地媒体库与浏览器中，不再与 115 APK 的原生播放历史同步。
- 旧版本保存的原生媒体子页面状态自动回到本地资料库。

## 数据与保留能力

**升级不会因此删除已有本地数据库，也不会清理你在 115 上的观看记录、听单、相册或文件。**

本地电影、剧集、专辑、歌曲、图片等资料、全文搜索、远端文件索引、跨账号副本、同步任务、备份恢复及整理流程保留。文件浏览、下载、WebDAV、File Provider 和普通媒体预览继续使用现有能力；下载仍取原文件。

为保持本地索引完整性，仅在索引器内部保留最小的只读图片变化接口；文件绑定的字幕读取和视频取源也保留。这些基础接口不再作为原生媒体库管理功能暴露。

## 验证与边界

- 20 项后端集成测试通过；真实账号变更测试保持跳过。
- 32 项本地库／原生入口移除／清晰度专项在手机 Chrome、WebKit 与桌面 Chrome 通过。
- TypeScript、94 个 Vue 模板校验及生产前端构建通过。
- 生产包审计未发现已移除的原生媒体入口或接口；本地数据库等核心实现文件与精简前一致。
- 浏览器是否能直接播放某个转码源仍取决于其容器、编码与 HLS 支持；不支持时明确提示使用外部播放器，不新增媒体代理。

建议升级前备份配置及数据目录。此次发布不包含尚未完成的 Android 原生工程。
