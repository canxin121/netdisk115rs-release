# v0.5.0：手机端单一页头、默认不多选与复制直链

本版集中收口手机（`compactLayout`）网页的页面结构，补上文件直链复制，并首次把独立 Android 客户端源码并入主仓库。桌面端行为、后端协议、数据库 schema 与媒体布局契约不变。

## 手机端页面结构

- 每个页面收敛为**唯一一行顶栏**：标题、返回、新建、刷新、搜索、选择、视图、更多全部在 `MobileNavigation` 的 app bar 同一行内渲染；各面板通过 `Teleport` 把自己的动作送进 `#mobile-app-actions`，不再各起一条工具条。
- 其下最多保留一条 44px、不换行的紧凑条：媒体中心面包屑、媒体管理区域切换、最近／分享／任务／离线的分类条。放不下的控件（搜索框、排序、操作类型、统计文本）改走底部弹层或并入该条的 `<select>`。
- 修正搜索态下传送宿主被卸载导致的白屏：`#mobile-app-actions` 与搜索框改用 `v-show` 常驻，节点身份在切换时不再变化，搜索页与面板同时挂载时也不会报 `Failed to locate Teleport target` 或 patch 到 null 节点。
- 回收站、任务、分享、最近、离线的工作条不再无条件常显，只在显式多选模式出现；系统返回手势可退出多选。

## 默认不多选

- `mobileSelecting` 只读标签自身的显式多选标记，不再由「选择集非空」派生。普通点按始终是打开，勾选框只在进入多选模式后出现。
- 网格、列表、媒体中心与画廊的自动选中（挂载即写入选择集）已移除，只保留主预览的 `activeId`。
- 选择态相关 store 方法加入幂等短路：原先 `tabs.value = tabs.value.map(...)` 每次生成新数组，空写也会同步唤醒 `flush: 'sync'` 观察者，导致面板自激递归并让页面永久停在加载态。

## 封面与文件名

- 网格封面改为铺满格子（正方形、随列宽缩放），不再写死 48px；骨架卡与真实卡片同尺寸。
- 文件名固定两行，封面不再压住名称；收藏星标与多选框收到封面四角内缩位置。
- 手机网格默认 3 列，横屏固定 4 列（封面铺满后按列数翻倍会重新变小）。
- 媒体中心接入与文件页相同的手机列数偏好，列表缩略图容器统一到 40px。

## 复制直链

新增「复制直链」入口：右键菜单（单个与多选）、QuickLook、详情面板、文件预览页、音频／视频播放器、文档预览，以及媒体中心检查器。

- 直链由服务端按访问方 UA 临时签发，约 10 分钟内有效；每次复制重新签发，不缓存、不落盘。
- 剪贴板被浏览器拒绝时（非 HTTPS、无用户激活）改为在托盘里展示文本供手动复制。
- 播放器的「用其他播放器打开」与「复制直链」共用同一套票据。

## 手机端移除暂存区入口

右键菜单的「加入暂存区」在手机端不再显示（桌面保留）；内部拖拽移动依赖的 `holding` 状态不变。

## Android 客户端源码并入

独立的 Kotlin／Compose 客户端（`android/`）进入本仓库：DocumentsProvider、本地备份、保留离线、多连接设置、回收站、播放票据转交与诊断页面。它不加载 WebView，也不改变网页路由或媒体库；仍为草稿阶段，**本版 Release 包不包含 APK**，Android 工作流只产出构建产物与模拟器测试报告。

## 升级与验证

本版不迁移数据库 schema，不清空索引、媒体库或云盘数据；建议升级前备份配置与数据目录，再用既有安装器升级。重启后新二进制与 Web 资源一起生效。

发布候选在本提交上通过以下检查：

- 浏览器回归 `bun run test:browser`：**241 项通过，0 失败，0 不稳定**（桌面 Chrome 31 项、Pixel 7 模拟 105 项、iPhone 13 模拟 105 项，无重试）。
- 手机专项 `bun run test:mobile`：**210 项通过，0 失败**。
- `vue-tsc --noEmit`、95 个 Vue 模板校验、生产构建全部通过。
- Android `./android/check.sh`：**BUILD SUCCESSFUL**，11 项协议测试与 3 项手机分类／排序测试通过（0 失败），Lint **0 错误、15 警告**（1 项目标 SDK、11 项依赖版本、3 项可用空间提示，未使用 baseline 掩盖）。
- 真实云盘变更套件仍按计划跳过；本版不宣称已在用户文件上执行破坏性联调。

手机端多顶栏的逐页实测结论：文件、我的收藏、搜索、回收站只有 1 条页头；媒体中心、媒体管理、最近、任务、分享、离线下载为 1 条页头 + 1 条 44px 紧凑条；预览页保持两行不变。
