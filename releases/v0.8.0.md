# v0.8.0：手机常用导航、两行顶栏与视频全屏手势

手机浏览器现在优先展示文件、媒体和离线下载；标题与页面操作分行显示，视频全屏增加按比例调整方向、横滑进度、亮度和音量手势。此次更新适用于网页，不包含 Android 原生客户端改动或 APK。

## 更容易到达常用功能

- 底栏按「文件 → 媒体 → 离线下载 → 更多」排列。最近、任务、收藏、分享和设置等从更多进入，进行中任务仍有数量提示。游客只显示有权限使用的入口。
- 顶栏分为标题行和页面工具行；无操作时隐藏空工具行，操作较多时允许换行。搜索切换保留工具栏节点，避免操作按钮丢失。
- 常用操作使用图标按钮，操作面板保留完整文字；主要触控区域至少为 44px，保留读屏名称和键盘焦点提示。
- 文件列表长名称最多显示两行。任务、分享、回收站、最近和离线下载在普通浏览时移除隐藏勾选框留下的空列；离线任务恢复显示文件大小。
- 调整底栏选中态、间距、安全区域及窄屏深浅色显示。共享侧栏也按常用功能顺序排列。

## 视频全屏与触屏操作

| 操作 | 行为 |
| --- | --- |
| 进入全屏 | 按视频宽高比请求横屏或竖屏。浏览器不支持方向锁时旋转整个播放区域，控件、字幕、进度条和画面手势使用一致坐标。手机实际转向后撤销多余旋转。 |
| 左右滑动画面 | 显示目标时间和变化秒数，松手后提交一次跳转；整屏跨度最多 90 秒，短视频按时长缩小，进度限制在视频范围内。 |
| 左半屏上下滑 | 调整视频画面亮度，范围为 20%–150%。 |
| 右半屏上下滑 | 在支持的浏览器中调整视频音量；iPhone / iPad 提示使用手机侧边音量键。 |
| 单击 / 双击画面 | 单击显示或收起控件，双击播放或暂停。 |
| 锁定屏幕 | 关闭画面手势与控制栏操作，保留解锁按钮；退出全屏后自动清除锁定。 |

画面手势仅在手机全屏启用，普通页面仍可纵向滚动。手势取消、多指介入、切换页面或坐标旋转时，未提交的跳转会取消；手势后的合成点击不会误触播放。暂停时中央播放按钮不会与手势反馈重叠。全屏设置使用播放器内部侧栏，返回先关闭设置，再退出全屏；退出和卸载会释放方向锁，并处理迟到的全屏请求。

## 浏览器能力与兼容性

- 亮度调整只影响视频画面，不改变设备系统亮度。iOS 的系统音量仍由硬件按键控制。
- 手机 Safari 的系统视频全屏会隐藏自定义手势和控件，因此优先使用元素全屏或页面全屏。页面全屏无法保证隐藏浏览器地址栏及系统状态栏。
- 交互参考第三方哔哩哔哩客户端 [PiliPala](https://github.com/guozhigq/pilipala) 的功能与方向处理；浏览器适配依据 [ScreenOrientation.lock](https://developer.mozilla.org/en-US/docs/Web/API/ScreenOrientation/lock) 和 [HTMLMediaElement.volume](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/volume) 的兼容性。未实机验证官方哔哩哔哩 App。
- 本版不迁移数据库 schema，不改变媒体目录布局、WebDAV 契约、视频直连来源或现有播放进度数据。

## 验证与升级

本地全量手机初测加修复后的专项复测，最终对应手机 Chrome / WebKit 239 项通过、1 项条件跳过；桌面 Chrome 32 项通过。跳过项是 WebKit 不支持的 Chromium CDP 触摸注入，两种引擎的 PointerEvent 手势用例均通过。TypeScript、96 个 Vue 模板检查和生产构建通过；最新构建包在两种引擎中各通过 11 组页面与交互检查。测试隔离账号 API，使用合成视频，没有操作真实云盘文件；浏览器模拟不等于实体手机验收。

使用发布仓库现有安装器升级程序和 Web 静态资源，完成后刷新手机浏览器。安装器保留已有配置、账号状态和数据目录。六个平台的安装包由发布流水线固定到同一源码提交构建；具体提交、安装检查结果及 macOS 包类型见下方发布构建记录。
