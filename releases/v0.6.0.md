# v0.6.0：直链改成看得懂的路径、手机顶栏动作策展

本版做两件事：把复制出去的直链从一串 43 位随机票据改成**看得懂文件名的路径形状**，并把上一版收得过头的手机顶栏动作重新收敛到「点得到、按得准」。后端仍是同一个二进制、同一套票据表，桌面端布局与媒体布局契约不变。

## 直链改成路径形状

复制直链不再是一串 43 位随机票据，而是把文件路径放进 URL：

```
https://your-host/d/影视/电影/家庭影像-2026.mkv?k=4YoDDkPiKs7OBd0v9zy6SLq
```

一眼看得出是哪个文件，下载器也会自动存成正确的文件名。密钥改成 16 随机字节的 22 位 URL-safe base64（≈128 bit），仍是不可猜测的随机能力票据，不携带账号、路径或文件信息，授权判断依旧完全在服务端进程内的票据表里。

- 直链由服务端按访问方 UA 临时签发、约十分钟有效；**媒体字节仍然完全不经本服务**，服务端只回一个空响应体 302，播放器／下载器自行连接 115 CDN。
- 新形状与 `/api/media/t/{token}` 查同一张票据表：**一个文件始终只有一条票据记录**，两种形状是同一条记录的两种渲染，淘汰压力不变。给外部播放器的 scheme 链接（`vlc://` 等）仍使用不透明形状，避免裸 UTF-8 路径被各家 scheme 解析改写。
- `/d/` 刻意不放在 `/api/` 下，因此第三方播放器与下载器**无需 Cookie**即可访问；已注册路由优先于静态目录与 SPA 回退。
- 鉴权顺序是「密钥 → UA → 路径核对 → 兑现」：服务端先按 URL 里的路径 `stat` 出一个文件、并要求它的 `pick_code` 与票据一致，通过后才签发 115 直链。**改名或移动后旧链接失效（404），乱改路径也是 404**，且不泄露文件是否存在；密钥无效 410，缺 UA 400。
- 路径只解码一次。真实文件名里的 `%` 是合法字符，处理时不会被二次解码改写成别的名字。
- WebDAV 挂载不能占用 `/`、`/api`、`/assets`、`/d`：这些是服务保留前缀，落在 `/d` 的挂载会静默吃掉直链，配置校验直接拒绝。

界面上不需要多用一步：右键菜单、QuickLook、详情面板、预览页、音视频播放器与媒体中心复制出来的都自动是新形状；没有父目录可用的调用点（例如只拿到 pick_code 的内部调用）自动回落到旧形状，老客户端与播放器 scheme 不受影响。

## 手机顶栏：动作策展与可达性

v0.5.0 把每个页面的动作压进唯一一行顶栏，但压过头了：`.mobile-app-actions` 是顶栏里唯一可伸缩的项且右对齐 + `overflow: hidden`，动作一多就同时（a）把标题挤到 38~76px，（b）从**左缘**溢出被裁掉。被裁掉的按钮不是「不好点」，而是**完全点不到**——裁切区域不接收指针事件。320px 下实测「排序与显示」渲染在 right:145 而宿主起点 149.4，点击只会命中旁边的常驻按钮。

- 每个页面顶栏最多 **3 颗平铺图标 + 1 颗 `⋯`**。`⋯` 保持纯图标，弹层标题说明这一组是什么（「文件选项」「媒体库选项」「媒体条目更多操作」「最近记录选项」「全部任务操作」……），弹层里始终是该页**完整**的动作清单。
- 进顶栏的每颗按钮统一 **44×44**（苹果／安卓的最小触控尺寸），动作组整组收缩、绝不换行、绝不被裁。
- 低频动作（刷新、清空、路径输入、筛选等）一律进具名弹层。
- 同一屏不再出现两颗同名按钮：预览页的「复制直链」只在最外层保留一颗，PDF／文本／DOCX／EPUB 里的重复副本已删除；图片下载只留在「图片操作」弹层里。
- 快速预览（QuickLook）的动作改传送到与文件页**互斥**的宿主：两者共用时顶栏会叠成 9 个按钮。
- 修复一个由此引入的功能回归：弹层里的表单提交按钮点击后不再同步关闭弹层。同步卸载宿主会让浏览器在执行默认动作（submit）之前就把表单移出文档，整次提交被静默丢弃——文件页「前往」跳页曾因此完全无反应、也没有任何报错。
- 媒体管理的三个区域共用同一条 44px 紧凑条（区域自己的筛选控件落在条尾），离线下载的「离线概览」整块收进顶栏弹层，各自的第二条带删除。

## 回归守卫

`web/tests/mobile/page-fixtures.ts` 新增 `appBarActionsReachable(page)`：逐颗量取传送进顶栏的按钮盒子，任一越界或小于 44px 即失败；`pages.mobile.spec.ts` 的末位用例在 320px 下逐页调用。这类裁切只查「页面有没有横向溢出」是看不出来的。

## 升级与验证

本版不迁移数据库 schema，不清空索引、媒体库或云盘数据；建议升级前备份配置与数据目录，再用既有安装器升级。重启后新二进制与 Web 资源一起生效。

发布候选在本提交上通过以下检查：

- `cargo test --locked`：**403 项通过，0 失败**（353 项库测试 + 各集成套件，含 `/d/` 路径解码、路径篡改 404、密钥无效 410 等新增用例）。
- 浏览器回归 `bun run test:browser`：**246 项通过，0 失败，0 不稳定**（桌面 Chrome 32 项、Pixel 7 模拟 107 项、iPhone 13 模拟 107 项，无重试）。
- `vue-tsc --noEmit`、95 个 Vue 模板校验、生产构建全部通过。
- 直链的正向 302 需要真实 115 账号与网络，测试环境无账号；建议升级后用一条真实链接自查：`curl -I` 该链接应得到 302 且 `content-length: 0`，把路径任意一段改掉应得到 404。

## 兼容性

- 老形状 `/api/media/t/{token}` 完整保留：既有测试、外部播放器 scheme 与旧客户端继续可用。
- 桌面端布局、数据库 schema、媒体库索引与媒体目录布局契约均不变。
